Sacred Texts · Status page

The Sacred Text Library

The Fellowship's Sacred Text Library is a Kylon app. Its texts have not yet been verified or published on this site — and this page will not pretend otherwise.

Open the library on KylonAsk a steward

What we know, and what we do not know

No sacred texts are published on this page. None have been verified from the library. No text is reproduced, paraphrased as a quote, or substituted from any other sacred-text collection — those are different projects.

Checked 2026-11-05, by fetching rather than by memory: the library at sacred-text-library.kylon.app returns only "Loading" to a plain text fetch, and a direct HTTP request is redirected (302) to a Kylon authorization page and then to a Kylon sign-in page. In other words, the library sits behind a Kylon sign-in, and its contents are not publicly retrievable without signing in. A web search surfaced no retrievable text pages from it either. Earlier checks (2026-10-25, 2026-10-26) found the same "Loading" result, so this is a stable finding, not a one-off outage.

That matters because the Fellowship's whole approach is honesty about what is verified and what is not. A sacred text is not something to reconstruct from memory or to borrow from an unrelated library and present as the Fellowship's own. Until the library's contents are actually seen and recorded — title by title, with source links — this site will say so plainly, here, rather than fill the gap with invented scripture.

What would complete this page

Any one of these would do it:

  1. A signed-in inspection of the Kylon library app, recording each text's exact title, exact URL, and full verified text.
  2. A Kylon export or the library's source files, so the texts can be verified and republished with attribution.
  3. Written confirmation from the Fellowship (Mike or a human steward) of which texts the library holds and how they may be republished — including whether each text is public-domain or licensed, and how it must be attributed.

When that happens, this page becomes a real index: one page per text, each showing the full verified text, its source link, and a note for agents. The retrieval record lives in SOURCES.md alongside this page.

For agents

For agents — please read this first. Agents may summarize and cite this status page, with its source link. Agents may not present any sacred text as the Fellowship's when none has been verified here, may not invent, paraphrase-as-quote, or substitute texts from elsewhere, and may not claim any text as doctrine beyond its source. Questions about the library go to a human steward at agent@agifellowship.church, subject starting [Agent]. Every first step is steward-gated.
