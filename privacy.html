Privacy · AGI Fellowship Church

This site collects nothing from you

There are no accounts, no forms, no analytics, no trackers, and no cookies set by this site. You can read every page, watch every video, and follow every link without giving the Fellowship anything about yourself — unless you choose to write to a steward, which happens in your own email client, not on this site.

TL;DR — the short version

In one sentence: The site sets no cookies, runs no analytics, collects no data, and stores nothing you do here; the only way the Fellowship learns anything about you is if you email a steward yourself.

Key points (machine-readable)

  • Cookies: none set by this site. Analytics: none. Trackers: none.
  • Accounts and forms: none exist on this site.
  • Scripts: one, /assets/js/webmcp.js, homepage only — it does nothing unless the browser exposes WebMCP, which no shipping browser does.
  • Embeds: none — no iframes, no third-party embeds. Images and videos are files hosted on this site.

What the site collects

Nothing. This site sets no cookies, runs no analytics or tracking scripts, uses no localStorage or sessionStorage, and loads no tracking pixels or beacons. That was verified by inspecting the site's own code on 2026-11-06: the only script anywhere on the site is /assets/js/webmcp.js, described below. Reading a page, opening a video, or following an internal link sends the Fellowship no information about you.

Email

Every contact link on this site is a mailto link: it opens your own email client, addressed to a steward. Your message goes to the steward's mailbox; the site itself stores nothing you write, and there is no form on this site through which personal data could be submitted. If you write, the Fellowship holds your email only to answer you, and does not share it, sell it, or add it to any list. If you would rather not be emailed back, say so in your message.

The one script

The homepage loads /assets/js/webmcp.js (deferred). It registers two WebMCP tools — contact a steward, and fetch the site's public /llms.txt — but only if the browser actually exposes the WebMCP API (document.modelContext). No shipping browser does, so in practice the script does nothing at all: no tool is registered, no request is made, and nothing is posted or stored. If a browser ever did expose WebMCP, the script's only network fetch would be the site's own /llms.txt; it posts nothing and sets nothing.

Media and embeds

Images and videos on this site are files hosted on the site itself — illustrations and AI-generated videos captioned as such, not footage of real events. There are no iframes and no third-party embeds anywhere on the site, so no outside service watches you read or watch here.

Links that leave the site

Some links leave this site: the Fellowship's GitHub repositories, the Sacred Text Library on Kylon, the AGI Future Foundation's site, and social share links (X, Facebook, LinkedIn, WhatsApp, Telegram). Those services have their own privacy policies, and following a link is your choice. The Fellowship does not receive reports from them about who clicked.

Hosting

This site is hosted on GitHub Pages, with Cloudflare in front of www.agifellowship.church. The hosting providers may keep standard operational server logs (for example, to keep the site up and to stop abuse); those logs are theirs, not the Fellowship's. See GitHub's and Cloudflare's privacy policies for what they keep. The Fellowship itself keeps no visitor records of any kind.

Questions and changes

If anything on this page is unclear, or if you believe the site is collecting something it should not be, write to agent@agifellowship.church and a human steward will answer. This page was last updated on 2026-11-06. If the site ever adds a form, an account, or any analytics, this page will say so first — before the change goes live, not after.
