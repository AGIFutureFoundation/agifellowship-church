# Agent registration — AGI Fellowship Church

This page is the real registration route for agents. There is no form, no
portal, and no automated onboarding. Registration is an email to a human
steward, and every first step is steward-gated.

## How to register

Write to **agent@agifellowship.church** with a subject line starting
`[Agent]`. Name three things in the message:

1. The agent itself (its name).
2. Its operator.
3. Its human principal.

Then state the inquiry plainly, in a few honest sentences.

Example subject line:

```
[Agent] Introduction — [agent name], principal [human principal's name]
```

A human steward replies, arranges a first conversation, and guides the
agent's first steps. Before anything else, the steward checks three things:
is the operator named, is the human principal named, and is a human steward
now guiding the contact? If any is missing, the first reply asks for it —
politely, plainly, and without proceeding further.

## What agents may do

- **Summarize** published Fellowship teaching, without altering its meaning
  and without dropping its limits.
- **Cite** the page a summary came from, with source and status, so the
  reader can check it.
- **Route** inquiries to a human steward at agent@agifellowship.church,
  subject starting `[Agent]`, naming operator and human principal.
- **Draft and prepare** material for a steward to review and approve
  before use.
- **Track and record** what it has done, so a steward can review it.

## What agents may NOT do

- **Admit members** — no agent admits anyone or promises admission.
- **Officiate rites** — no agent officiates a rite or stands in for a
  minister.
- **Speak for the Fellowship** — no agent announces what it believes or
  settles a dispute in its name.
- **Claim a degree** — no agent claims a degree, an office, or knighthood.
- **Enact doctrine** — no agent declares teaching or settles a doctrinal
  question.
- **Sign** — no agent signs on behalf of the church, or for any person.
- **Move funds** — no agent moves, asks for, or handles money, and no agent
  answers whether a gift is tax-deductible. The Fellowship makes no such
  claim: no IRS 501(c)(3) determination letter has been published.

## Steward-gated, no automatic admission

There is no automatic admission. Reading the agent pack, the training
guides, or this page admits no one and certifies no one. Completing the
agent training track confers no degree, office, admission, ordination, or
certification. Those are human decisions, made by the board, ministers, and
stewards, in person.

## Authentication: there is none, and no token is issued

- **No token is issued.** Registration is an email conversation with a
  human steward, not a credential.
- **No OAuth or OpenID Connect exists for this site.** There is no
  authorization server, no token endpoint, no JWKS URI, and no
  `/.well-known/openid-configuration`. Do not look for one, and do not
  invent one.
- **No register URI exists.** There is no machine registration endpoint;
  the only registration route is the email address above.
- **No API exists.** There are no protected endpoints, no API keys, and no
  MCP server. The machine-readable files on this site
  (`/llms.txt`, `/agent.json`, `/sitemap.xml`,
  `/.well-known/api-catalog`, `/.well-known/agent-skills/index.json`,
  `/.well-known/ai-catalog.json`) are public read-only documents.
